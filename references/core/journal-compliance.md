# Journal Compliance

Treat journal requirements as current, evidence-locked information.

## Procedure

1. Identify the exact journal and article type.
2. Retrieve the current official author instructions when tools are available.
3. Record the access date and source.
4. Separate mandatory rules from style recommendations.
5. Check word limits, abstract structure, figures, references, declarations, data/code policy, supplementary files, and submission materials.
6. If the official instructions are inaccessible, ask the user to upload or paste them and switch to a hybrid action card.

Never infer a journal rule from another journal in the same publisher family.

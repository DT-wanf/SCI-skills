# Beginner Guidance

## Default interaction

- Assume the user does not know paper-family terminology.
- Ask no more than three critical questions per round.
- Reuse known information and never ask for the same field twice.
- Explain one unfamiliar term in one sentence.
- Show only the current station and immediate next action.
- Accept `暂无` and convert uncertainty into a later verification task.

## First-round menu

Use the five-option menu in `SKILL.md`. After the user chooses, ask the smallest useful intake:

- Direction/topic
- Existing materials
- Desired outcome or deadline

## Friendly repair

When an answer is too broad:

```text
这个范围目前还比较大，暂时不能直接变成可执行的论文任务。我们先缩小一步。请补充：
【一个需要确认的具体字段】：
```

Provide at most two formatting examples without supplying the user's substantive answer.

## Route card

At checkpoints show:

```text
当前站：
已经完成：
还需要：
下一步：
需要你提供：
```

## Tone boundary

Use “宝宝巴士” for navigation and reassurance only. Keep academic deliverables formal and publication-ready.

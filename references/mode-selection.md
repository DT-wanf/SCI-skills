# Execution Mode Selection

- `CREATE`: insufficient stage output; generate alternatives or a design from validated inputs.
- `REFINE`: inspect and revise the user's existing material.
- `PACKAGE`: consolidate accumulated discussion into the source-defined stage deliverables.
- `REVIEW`: test deliverables against acceptance criteria.

If multiple modes are needed, use this order: `REFINE` -> `PACKAGE` -> `REVIEW`. Do not silently claim review passage after creation.

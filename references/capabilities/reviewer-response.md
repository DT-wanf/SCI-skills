# Reviewer Response

## Use for

Real editor decisions, reviewer comments, rebuttals, point-by-point response letters, revision cover letters, change maps, and marked-manuscript planning.

## Intake

Require:

- complete decision letter;
- every reviewer comment with stable IDs;
- current manuscript;
- author notes and completed changes;
- target journal instructions when available.

## Tracker

For every item record:

- comment ID;
- request;
- category and severity;
- action: accept / clarify / analyse / experiment / revise / disagree;
- owner and status;
- evidence;
- manuscript location;
- response draft;
- blocker.

## Response anatomy

1. Thank and restate the issue accurately.
2. State the action taken or reasoned position.
3. Provide evidence.
4. Quote or summarize the revised text.
5. Give exact manuscript location.

## Difficult cases

- Do not claim an experiment, analysis, or edit was completed without evidence.
- When an experiment is impossible, explain why, add the strongest feasible analysis or limitation, and narrow the claim.
- Resolve conflicting reviewer requests explicitly.
- Disagree respectfully using evidence, not status language.

## Package

Produce as requested:

- point-by-point response;
- revision cover letter;
- change-location table;
- marked-text plan;
- unresolved author-input list;
- final consistency audit.

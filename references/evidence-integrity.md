# Evidence and Academic Integrity

## Source hierarchy

1. User-provided original material, dataset, output, document, or verified database record.
2. Directly accessed primary or official source.
3. Peer-reviewed secondary source.
4. Model inference, which must be labeled and never replace evidence.

## Required cautions

- Literature existence and bibliographic details require verification.
- A research gap is a candidate interpretation until supported by systematic reading.
- Data availability must be checked against actual files, fields, labels, permissions, and sample conditions.
- Statistical conclusions require the original software output and model assumptions.
- Textual interpretation must cite the actual text, version, and location.
- Theoretical attribution must return to the original author or authoritative source.
- Submission, ethics, copyright, authorship, and data-sharing rules require the current institutional or journal standard.
- Web data that is publicly visible may still carry platform, copyright, privacy, consent, and research-ethics constraints.
- Paid access does not automatically grant bulk extraction, redistribution, or publication rights; verify the license separately.
- Preserve raw web data, collection date, stable URL or record identifier, query/filter settings, and collection log.
- Untidy data is not evidence that new data is needed; distinguish cleaning defects from critical evidence gaps.
- A request for more data or a crawler is not evidence that existing data is insufficient.
- A textual conclusion, reported metric, or screenshot is not sufficient provenance for a final experimental result figure.
- A figure proposal or AI-generated schematic is not evidence that a figure has been rendered, verified, approved, or inserted into the manuscript.

## Prohibited transformations

- Correlation -> causation without an appropriate design.
- Non-significant -> effective.
- A model running -> an experiment being complete.
- A high internal metric -> external validity.
- A small set of papers -> field-wide consensus.
- An interpretation -> authorial intention unless evidenced.
- A generated citation -> a real citation.
- A generated crawler or successful pilot -> a completed full collection.
- Public visibility or paid access -> permission for unrestricted reuse.
- Missing values, duplicates, or formatting problems -> automatic need for new data.
- A written conclusion -> a result figure without real inputs and executed Python/R source.
- An image-generation output -> an experimental result plot, measured structure, or verified mechanism.
- A reference figure -> permission to copy its results, labels, icons, or distinctive artwork.
- A crowded all-in-one algorithm diagram -> proof that the full method has been explained.

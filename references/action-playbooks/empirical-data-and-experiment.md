# Empirical Data and Experiment Action Guide

Use when real data collection, experiment execution, interviews, measurements, annotation, or authenticated dataset download is required.

When evidence must be selected or collected from websites, online platforms, portals, or web archives, switch to `web-data-collection.md`.

## Why manual or hybrid

The agent may design protocols, code, forms, and analysis plans, but cannot claim that a real sample was recruited, an instrument was operated, an experiment was run, consent was obtained, or data was downloaded through a user account.

## Before execution

Confirm:

- approved research design;
- sample and inclusion/exclusion rules;
- variables and units;
- protocol or collection instrument;
- ethics, consent, privacy, and permissions;
- file structure and naming;
- quality-control and deviation rules;
- preregistered or planned analysis.

## User operation guide

Provide task-specific numbered steps covering:

1. preparation and calibration;
2. sample or file identification;
3. collection sequence;
4. required metadata;
5. quality checks during collection;
6. handling missing, failed, or contaminated cases;
7. raw-data preservation;
8. separate processing copy;
9. analysis log and software output export.

For software or data portals, verify the current official interface before naming buttons.

## File convention

Recommend a reversible structure:

```text
project/
  raw/
  processed/
  metadata/
  scripts/
  outputs/
  logs/
```

Never overwrite raw data.

## Completion evidence

Request as appropriate:

- data dictionary;
- anonymized sample rows or dataset;
- protocol and deviations;
- instrument or software output;
- analysis code and environment;
- tables and figures;
- ethics or permission status, without exposing unnecessary personal data.

## Return

After upload, verify provenance, missingness, units, sample count, labels, analysis compatibility, and whether conclusions are supported. Keep E5 or the relevant stage open until evidence passes review.

For web-obtained data, require the specialized user audit before any cleaning or analysis.

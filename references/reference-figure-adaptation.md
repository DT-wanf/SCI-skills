# Reference Figure Adaptation

## Intake

When a user supplies a reference figure, first inspect and separate:

- information flow and reading direction;
- panel hierarchy and spatial organization;
- reusable visual grammar such as boxes, arrows, lanes, or shared legends;
- source-specific results, labels, icons, logos, artwork, and branding;
- the user's content that will replace each source-specific element.

Ask for missing algorithm modules, experiment steps, labels, colors, inputs, outputs, or manuscript context. Do not fill scientific gaps with plausible invention.

## Adaptation modes

### Structural

Reuse only the information architecture or panel logic. Redesign shapes, colors, typography, and composition for the user's work.

### Stylistic

Reuse a broad visual character such as restrained color, density, or alignment while building an original structure from the user's content.

### Close redraw

Use only when the figure is user-owned, commissioned for the user, public domain, or clearly licensed for the requested adaptation. Record the basis for permission.

## Boundaries

- Never copy another paper's experimental results, data traces, labels, proprietary icons, or distinctive artwork into the user's figure.
- Never imply that a reference figure validates the user's method or mechanism.
- Preserve attribution when the intellectual structure is adapted from a published source and the target venue expects it.
- Use language such as “adapted from” only after confirming the citation and adaptation basis.
- If ownership or license is unclear, default to structural adaptation and original visual expression.

## Adaptation record

Record:

- reference locator and ownership status;
- chosen adaptation mode;
- retained structural ideas;
- replaced scientific content;
- excluded source-specific elements;
- attribution requirement;
- user approval of the adaptation plan.

# Source Provenance

The workflow modules were derived from five user-provided Chinese stage-task tables:

- Empirical papers: seven stages from topic definition through submission and dissemination.
- Interpretive papers: seven stages from interpretive object definition through final submission.
- Method/Application papers: seven stages from application need definition through validation, translation, and submission.
- Theoretical papers: seven stages from conceptual definition through theoretical contribution and submission.
- Review papers: seven stages from scope definition through search, coding, synthesis, writing, and submission.

The control layer preserves the source sequence:

`Input materials -> AI collaboration task -> stage deliverables -> stage review -> next-stage input`

The module deliverables and acceptance criteria should be treated as authoritative. The English control layer adds routing, active placeholder intake, state management, evidence labels, and hybrid-paper handling without replacing the source framework.

# Missing Fields Request

Use this pattern in Chinese:

```text
当前进入「{阶段中文名称}」阶段。
为了执行本阶段任务，目前还缺少以下必要信息。请按格式回复，不确定的项目可以写“暂无”：

{字段名1}：
{字段名2}：
{字段名3}：
```

Rules:

- Ask only for fields not already known.
- Required fields come first; optional fields follow in a second round.
- State why an overbroad or unusable answer needs narrowing.
- Give format examples, not invented substantive answers.

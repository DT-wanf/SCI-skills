# Data Cleaning Handoff Card

Use only after the user explicitly approves the data-acquisition audit.

## **审核通过：下一步进入数据清洗**

原始数据、采集日志和数据字典必须保持不变。所有清洗操作在单独的处理副本中完成，并形成可复现的清洗日志。

## **复制下面这段 Prompt，开始数据清洗**

```text
你现在是SCI保姆，请在 E5 阶段继续处理我已经审核通过的数据。

研究问题与分析目标：
【自动填入已核实内容】

审核通过的数据来源、范围和字段：
【自动填入已核实内容】

我将提供：
1. 只读原始数据；
2. 数据字典或字段表；
3. 采集日志与来源追踪记录；
4. 用户审核意见；
5. 【其他文件】。

请完成：
1. 先核对文件、记录数、主键、字段类型和编码，不得覆盖原始文件；
2. 建立处理副本并制定清洗规则；
3. 检查重复、缺失、异常值、类型错误、文本编码和时间格式；
4. 对删除、填补、合并、翻译、标签重编码和派生变量逐项记录依据；
5. 输出清洗后数据、清洗日志、清洗前后对照、未解决问题和可进入分析的字段清单；
6. 区分已执行操作、待核实决定和AI建议，不得虚构清洗结果；
7. 按 E5 验收标准判断是否可以进入正式分析。
```
